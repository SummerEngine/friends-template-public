# Provenance: what ships and where each part comes from

Every row is a shipped directory or file group. "Ours" means written or authored in this project by its developers (with AI coding assistants as tools).
"Generated" means produced by a named model/API from our prompts; the generator is named only where it can be shown from the repository,
its tools or its provenance files. Licence of everything marked "ours" or "generated by us" is the project's own.

`demo/levels/level_NN.json` are designed in this repository from scratch: every block, hazard and number is placed on the

`tools/level_lint.py`.
